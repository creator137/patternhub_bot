# Проверка фильтров, 28 октября 2026

## Причины нулевой выдачи

Это были пропуски данных, а не SQL-ошибка пересечения условий. Production до
исправлений: VikiSews beginner=0 / knit=0, SewItNow beginner=0 / knit=63,
Studio Yusupova beginner=0 / knit=23. Grasser и HelperSew имели размеченные товары.

- Listing VikiSews не содержит всей разметки detail page. Ежедневный upsert
  записывал False и NULL вместо ранее полученных флагов/описаний.
- Реальный тег VikiSews `Новичок` не распознавался как уровень начинающего.
- У Studio Yusupova `Трикотаж` — дополнительная категория (81 позиция в ответе
  справочника), но раньше сохранялась только одна subcategory.
- SewItNow отдаёт рекомендации по материалам в `initProduct.description` на
  detail page. На listing этого поля нет. Старые URL вариантов могут содержать
  сокращённый slug, поэтому идентичность проверяется также по реальному product ID.

## Изменения

`ParsedProduct.is_beginner/is_knit=None` означает «не передано», а не False.
На вставке это по-прежнему 0 в SQLite; на обновлении неизвестный флаг и отсутствующие
detail fields не стирают известные данные. Явный False может снять флаг.

Provider может вернуть полный/неполный `FilterSnapshot` с реальными товарами
раздела. Общий repository сопоставляет их по source_product_id/product_url.
Полный snapshot обновляет membership; неполный только добавляет подтверждённые
совпадения. Пустой snapshot не очищает разметку; резкое падение числа совпадений
более чем вдвое при прежнем count >20 тоже блокирует массовое снятие флага.
VikiSews обходит `/vykrojki/dlja-novichkov/` и `/vykrojki/trikotazh/` с пагинацией.
Это не snapshot доступности, он не скрывает и не удаляет товары.
`source_filter_snapshots` хранит время полного обхода каждого раздела: в течение
суток отсутствие тега на detail page не может снять подтверждённый разделом флаг.
Положительные detail facts при этом могут дополнить разметку. Это устраняет гонку
двух способов обогащения; неполный/аномально маленький обход не продлевает этот приоритет.

Ежедневная синхронизация вызывает общий контракт filter snapshots. Существующий
gallery worker дополнительно извлекает detail facts через provider-контракт;
`filters_checked_at` позволяет начать с ещё не исследованных товаров. Ошибки
сохраняются в существующей очереди с backoff. В handlers нет source-specific кода
и сетевого обхода сайтов. Новые товары подхватываются автоматически после импорта.

```bash
python -m app.filter_refresh vikisews
python -m app.media --mode filters --source sewitnow --limit 100
python -m app.media --mode filters --source vikisews --limit 100
```

Сведения о трикотаже берутся из категории или положительных рекомендаций самого
товара. Упоминание трикотажного дублерина либо запрета использовать трикотаж
само по себе не включает фильтр. Неизвестная сложность не превращается в beginner.

## Новизна и бесплатность

`is_new` по-прежнему означает явную метку производителя (Grasser/HelperSew).
Дата импорта не используется. `sort=new_first` поднимает эти модели вверх, сохраняя
полную выдачу с остальными выбранными условиями. В Mini App есть сортировка
«Сначала новинки» и переход из режима «Только новинки» к полному списку.
Это не сортировка по дате релиза всех пяти сайтов: общей подтверждённой даты пока нет.

Проверенный раздел Grasser `/vykrojki/besplatnye-vykrojki/` отдаёт товары за 1 ₽.
Они остаются платными, а не искусственно попадают в `is_free=True`.

## Вопросы клиентке

1. «Новинки»: нужны только отмеченные производителем, последние N дней по дате
   релиза, текущая коллекция или впервые обнаруженные после запуска сервиса?
   Это разные признаки; дата импорта не заменяет дату релиза.
2. Какие конкретные модели Studio Yusupova и SewItNow она относит к начинающим?
   Нужны 1–2 ссылки и критерий: отметка производителя либо собственная оценка.
   В проверенных категориях/описаниях этих сайтов отметка сложности не найдена.
3. «Бесплатные»: строго 0 ₽ или также «почти бесплатные» за 1 ₽? Сейчас строго 0 ₽.
4. «Трикотаж»: любой явно рекомендованный материал или только выделенный раздел
   производителя? У некоторых моделей допустимы несколько материалов.

Нельзя превращать отсутствие исходных сведений в выдуманную классификацию.
